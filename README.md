# 🌱 AgriChat - Community Platform for Farmers

AgriChat is a full-stack MERN (MongoDB, Express.js, React.js, Node.js) platform designed to empower agricultural communities, enabling farmers to share updates, ask questions, access market and pest control guidance, and interact in English and Kannada.

## 🚀 Quick Start (Backend)

1. **Install Dependencies:**
   ```bash
   cd server
   npm install
   ```

2. **Configure Environment:**
   Copy `.env.example` to `.env` and adjust variables if needed:
   ```bash
   cp .env.example .env
   ```

3. **Start Development Server:**
   ```bash
   npm run dev
   ```

4. **Verify Health Endpoint:**
   ```
   GET http://localhost:5000/api/health
   ```
